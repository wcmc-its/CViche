Feedback Nudge Strategy

How aggressively should we push users toward the Qualtrics feedback form? All options are non-blocking.

A

Badge + Banner Combo

Run History — Upload Page
📋 You have 2 runs awaiting feedback
Your feedback helps us improve CViche and supports our research
Give Feedback
Previous Runs
✓
SmithCV.docx
Mar 20 · 2m 38s · $0.215
Needs feedback
✓
JonesCV.docx

Feedback given

Persistent amber banner counting runs without feedback. Each run shows a badge: "Needs feedback" (amber) or "Feedback given" (green). Banner links to Qualtrics. Cannot be permanently dismissed — only goes away when all runs have feedback.

B

Badge + Banner + Upload De-emphasis

Upload Page with pending feedback
📋 2 runs awaiting feedback
Please share your feedback before starting another run
Give Feedback
📄
Click to select a file
Upload is available, but please consider giving feedback first

Same as A, but also visually softens the upload button when feedback is pending. Upload still works (not blocked), but the reduced contrast + gentle text nudge makes feedback the more prominent action.

C

Post-Completion Interstitial

After pipeline completes
✓
Pipeline Complete!
Your WCM-formatted CV is ready for download
Download CV Share Your Feedback (2 min) I'll do this later

When a run completes, show a completion screen with download AND feedback as equally prominent actions. "I'll do this later" dismisses but the run history badges from Option A still persist.

These are combinable. You could use A's run history badges + C's completion interstitial together for maximum coverage.
