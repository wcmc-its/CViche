<task type="auto">
  <name>Task 1: Create mirror clone and execute BFG passes</name>
  <files></files>
  <read_first>
    - .planning/phases/02-history-rewrite-and-tagging/02-RESEARCH.md (BFG command examples, HEAD protection, multiple passes pattern)
    - .planning/phases/02-history-rewrite-and-tagging/02-CONTEXT.md (purge targeting strategy, exact paths and extensions)
    - .planning/phases/02-history-rewrite-and-tagging/02-01-SUMMARY.md (confirm Task 1 completed -- src/logs/ removed from HEAD)
  </read_first>
  <action>
1. Verify prerequisite: src/logs/ files are not tracked in HEAD:
   ```bash
   git ls-files src/logs/ | wc -l
   ```
   Must return 0. If not 0, STOP -- Plan 01 must complete first.

2. Remove any leftover mirror from a previous attempt:
   ```bash
   rm -rf /tmp/cviche-clean.git
   ```

3. Create a working mirror clone:
   ```bash
   git clone --mirror . /tmp/cviche-clean.git
   ```

4. Run BFG Pass 1 -- Delete by extension (covers PDFs, Word docs, databases, Keynote, log data, archives):
   ```bash
   cd /tmp/cviche-clean.git && bfg --delete-files '*.{pdf,docx,sqlite,db,key,jsonl,tar.gz}' .
   ```
   Note: BFG's HEAD protection will preserve the two .docx template files that are still in HEAD (`cv_template_wcm.docx` and `wcm_cv_template_faculty_october_2022_final.docx`). The *.db pattern is safe because all .db files were git-rm'd in Phase 1.

5. Run BFG Pass 2 -- Delete specific sensitive files by name:
   ```bash
   bfg --delete-files 'auth_config.yaml' .
   ```
   This catches `web_interface/backend/auth_config.yaml` which contains real email addresses. The file was git-rm'd in Phase 1 so HEAD protection will not preserve it.

6. Run BFG Pass 3 -- Delete entire folder contents by folder name:
   ```bash
   bfg --delete-folders '{data,archive,node_modules,uploads,prompt_logs,prompt_logs_debug,dist,outputs,logs}' .
   ```
   This purges all contents from these directories across all historical commits. BFG matches folder names only, which is safe here because these names are unambiguous.

7. Print a summary of all changes BFG reported. Capture the output of each pass so it can be shown to the user at the checkpoint.

8. Run reflog expiry and aggressive garbage collection:
   ```bash
   cd /tmp/cviche-clean.git
   git reflog expire --expire=now --all
   git gc --prune=now --aggressive
   ```

9. Check the cleaned mirror size:
   ```bash
   du -sh /tmp/cviche-clean.git
   ```
   Expected: under 50 MB (down from ~275 MB).
  </action>

    <automated>test -d /tmp/cviche-clean.git && du -sh /tmp/cviche-clean.git | awk '{print $1}' && echo "Mirror exists" || echo "FAIL: mirror not found"</automated>
