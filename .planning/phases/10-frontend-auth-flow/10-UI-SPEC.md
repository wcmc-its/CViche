## Component Inventory

This phase does not create new components. It modifies two existing files:

### AuthContext.tsx modifications

| Addition | Type | Source |
|----------|------|--------|
| `AuthConfig` interface | TypeScript type | `{ mode: 'simple' \| 'saml', discovery_url?: string }` |
| `authConfig` state | `useState<AuthConfig \| null>(null)` | Starts null (loading), resolves to config or safe fallback |
| `fetchConfig()` | async function in mount useEffect | Fetches `GET /api/auth/config`, defaults to `{ mode: 'simple' }` on failure |

### LoginPage.tsx modifications

| Addition | Type | Visual behavior |
|----------|------|-----------------|
| Loading guard | Early return | Centered Loader2 spinner (h-8 w-8, text-gray-400) on headerbg.png background while authConfig is null |
| SSO button block | Conditional JSX | Full-width primary-600 button with Shield icon, replaces email form when mode is saml |
| Redirect state | `useState<boolean>(false)` | Button shows "Redirecting to WCM sign-in..." with Loader2 spinner after click |
| Subtitle conditional | Ternary in JSX | Different subtitle text for saml vs simple mode |

### Existing components used unchanged

| Component | File | Role in this phase |
|-----------|------|--------------------|
| ErrorBanner | `ErrorBanner.tsx` | Displays SAML error messages (already wired from Phase 8/9) |
| Loader2 | lucide-react | Loading spinner in guard and redirect state |
| Shield | lucide-react | SSO button icon (new import) |
| LogIn | lucide-react | Simple mode "Sign In" button icon (existing, unchanged) |

## Interaction States

### Login Page — Config Loading (authConfig === null)

| Property | Value |
|----------|-------|
| Layout | Full-screen centered on headerbg.png background |
| Content | Single Loader2 spinner, h-8 w-8, animate-spin, text-gray-400 |
| Duration | Typically < 200ms (local API call); fallback to simple mode on failure |
| Transition | Replaced by full card once authConfig resolves |

### Login Page — Simple Mode (authConfig.mode === "simple")

| Property | Value |
|----------|-------|
| Layout | Identical to current LoginPage — zero visual changes |
| Heading | "Sign In" (text-xl font-semibold text-gray-900) |
| Subtitle | "Enter your name and WCM email to get started." (text-gray-600 italic) |
| Form fields | Full Name, WCM Email (existing inputs unchanged) |
| CTA button | "Sign In" with LogIn icon (existing, unchanged) |
| Error display | ErrorBanner below form fields (existing behavior) |
| SAML error banner | Above form if redirected back with ?error= param (existing behavior) |

### Login Page — SAML Mode (authConfig.mode === "saml")

| Property | Value |
|----------|-------|
| Layout | Same card, logo, and background as simple mode |
| Heading | "Sign In" (text-xl font-semibold text-gray-900) |
| Subtitle | "Use your Weill Cornell Medicine credentials to sign in." (text-gray-600 italic) |
| CTA button | "Sign in with WCM SSO" with Shield icon (h-5 w-5) |
| Button style | `w-full bg-primary-600 text-white py-3 px-4 rounded-lg font-semibold hover:bg-primary-700 disabled:bg-gray-300 disabled:cursor-not-allowed transition-colors focus:ring-2 focus:ring-primary-500 focus:outline-none` |
| Button touch | `style={{ touchAction: 'manipulation' }}` |
| Below button | "You will be redirected to Weill Cornell Medicine sign-in" (text-sm text-gray-500 mt-3 text-center) |
| Email form | Not rendered (completely hidden) |
| SAML error banner | Above SSO button if redirected back with ?error= param (existing ErrorBanner) |

### Login Page — SSO Redirect In Progress (redirecting === true)

| Property | Value |
|----------|-------|
| Button state | disabled (bg-gray-300, cursor-not-allowed) |
| Button content | Loader2 spinner (h-5 w-5 animate-spin) + "Redirecting to WCM sign-in..." |
| Page behavior | Full-page redirect via `window.location.href = '/api/saml/login'` |
| Duration | Brief (< 1s typically); spinner visible until browser navigates away |

## Accessibility

| Concern | Implementation |
|---------|----------------|
| Focus visible | 2px solid #3b82f6 outline with 2px offset (global rule in index.css) |
| SSO button focus | `focus:ring-2 focus:ring-primary-500 focus:outline-none` |
| Icon accessibility | All icons use `aria-hidden="true"` (decorative, text label provides meaning) |
| Error announcement | ErrorBanner uses `role="alert"` for screen reader announcement |
| Dismiss button | `aria-label="Dismiss error"` on ErrorBanner close button |
| Loading state | Loader2 spinner is visual-only; no aria-live region needed (page replaces entirely) |
| Button disabled state | `disabled` attribute + `disabled:cursor-not-allowed` for visual cue |
| Reduced motion | Global `prefers-reduced-motion: reduce` rule disables `animate-spin` (in index.css) |
| Color contrast | primary-600 (#2563eb) on white text meets WCAG AA (contrast ratio 4.6:1 for large text/buttons) |
