## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside table cells, inline badge padding vertical |
| sm | 8px | Cell horizontal padding, gap between badge icon and label |
| cell | 12px | Table cell padding (px-3 py-3) -- density exception for scannable row height |
| md | 16px | Table cell vertical padding, container inner padding sides |
| lg | 24px | Container top/bottom padding, section heading margin-bottom |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Empty state vertical padding |
| 3xl | 64px | Not used in this phase |

Exceptions: 12px (`cell` token) is a valid multiple of 4, declared explicitly for table cell density. Standard 8px is too cramped for data rows; 16px wastes vertical space when displaying 100 rows. 12px provides the optimal balance for scannable table density.

## Typography

| Role | Size | Weight | Line Height | Usage in this phase |
|------|------|--------|-------------|---------------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 | Table cell text, pagination summary |
| Label | 12px (text-xs) | 400 (normal) | 1.5 | Column headers, feedback badge text, page numbers |
| Heading | 14px (text-sm) | 600 (semibold) | 1.5 | Section title "Previous Runs" |
| Display | not used | -- | -- | -- |

Rationale: The existing RunHistory uses text-sm (14px) for body and text-xs (12px) for secondary info. This phase stays consistent with the established type scale. The section heading matches the current `text-sm font-semibold` pattern. Label uses 400 weight (not 500) because the size difference (12px vs 14px) already distinguishes Label from Body without a separate weight.

## Visual Hierarchy

Primary focal point: status column color coding (draws the eye first via chromatic contrast against the neutral table).
Secondary focal point: filename text (largest flex column, natural reading position).
Tertiary focal point: pagination controls (bottom of card, accessed after scanning rows).

## Component Inventory

### Table Container
- Wrapper: `<section aria-label="Previous runs">` with class `mt-6 bg-white/95 backdrop-blur-sm rounded-lg shadow-lg p-6`
- Matches existing card container pattern used throughout UploadPage
- Section heading: "Previous Runs" as `<h2>` with `text-sm font-semibold text-gray-700 mb-3`

### Table Element
- Use semantic `<table>` element (not div grid) for accessibility
- `<thead>` with sticky header: `position: sticky; top: 0; z-index: 10` (uses existing z-header token)
- Header background: `#ffffff` / white with `border-b-2 border-gray-200` bottom border
- Table width: 100% of container

### Column Definitions

| Column | Header Label | Width | Alignment | Sort Key | Cell Content |
|--------|-------------|-------|-----------|----------|-------------|
| Status | Status | 120px min | left | `status` | StatusIcon (16x16) + text label with 4px gap |
| Filename | File | flex (takes remaining space) | left | `filename` | Filename text, wraps naturally (no truncation) |
| Date | Date | 140px min | left | `started_at` | "Mar 23, 2:15 PM" absolute format |
| Duration | Duration | 88px min | right | `total_duration_seconds` | "3m 42s" or em-dash for null |
| Cost | Cost | 72px min | right | `total_cost` | "$0.12" (2 decimal places) |
| Feedback | Feedback | 140px min | center | feedback status | Badge pill or empty |

### Sort Header Interaction
- Each `<th>` is a `<button>` for keyboard accessibility
- Active sort column: chevron icon (ChevronUp or ChevronDown from lucide-react) in primary-600 color, 12x12 size
- Inactive columns: no icon by default; on hover show ChevronDown in gray-400 at 12x12
- Cursor: `cursor-pointer` on all header buttons
- Click cycles: ascending -> descending (for the same column); clicking a new column sets it as ascending (except Date which defaults to descending)
- Header text: `text-xs font-normal text-gray-500 uppercase tracking-wider`

### Table Row
- Each `<tr>` wrapped in an interactive element: use `onClick` on `<tr>` with `cursor-pointer` and `role="link"`
- Hover: `bg-gray-100` transition-colors
- Zebra: odd rows get `bg-gray-50`, even rows get `bg-white`
- Running rows: `bg-primary-50` (overrides zebra)
- Cell padding: `px-3 py-3` (12px horizontal, 12px vertical -- uses `cell` spacing token for table density)
- Row border: `border-b border-gray-100` between rows

### Status Cell Content
- StatusIcon (existing component) at 16x16: CheckCircle2 (green-600), Loader2 with animate-spin (blue-600), XCircle (red-600), AlertCircle (orange-600), Clock (gray-400)
- Text label next to icon with 4px gap: "Complete", "Running", "Failed", "Cancelled", "Pending"
- Label color matches icon color
- Label font: text-sm font-normal

### Feedback Cell Content
- For complete runs with has_feedback=true: green pill badge (static `<span>`)
- For complete runs with has_feedback=false: amber pill badge (interactive `<button>` with stopPropagation)
- Badge: `px-2 py-0.5 rounded-full text-[11px] font-medium` with MessageSquare icon at 12x12
- For non-complete runs or runs not in feedbackMap: empty cell (no content)

### Pagination Bar
- Rendered below the table, inside the card container
- Layout: flex row, items-center, justify-between
- Left side: "Showing 1-100 of 247 runs" in text-sm text-gray-500
- Right side: page number buttons
- Previous button: ChevronLeft icon (16x16) with `aria-label="Previous page"`
- Next button: ChevronRight icon (16x16) with `aria-label="Next page"`
- Page numbers: `1 2 3 ... N` with ellipsis when total pages > 7
- Active page: `bg-primary-600 text-white` rounded-md px-3 py-1
- Inactive page: `text-gray-600 hover:bg-gray-100` rounded-md px-3 py-1
- Disabled prev/next: `text-gray-300 cursor-not-allowed`
- All page buttons: `text-sm font-normal`, min-width 32px, height 32px
- Margin-top from table: 16px (md spacing)
- Pagination only renders when total > 100 (page size)

### Loading State
- Matches existing pattern: centered `<Loader2>` spinner with "Loading history..." text
- `text-center py-4 text-sm text-gray-500`

### Empty State
- Currently RunHistory returns `null` when empty. The table redesign adds a proper empty state.
- Centered within the card container
- Icon: FileText at 48x48 in gray-300
- Heading: "No runs yet" in text-sm font-semibold text-gray-900
- Body: "Upload a CV above to start your first pipeline run." in text-sm text-gray-500, max-width 280px, centered
- Vertical padding: 48px top and bottom (2xl spacing)

### Error State
- Uses existing ErrorBanner component
- Displayed above the table within the card container
- Retry link within the error message

## Interaction Contract

### Sort Behavior
- Default: Date column, descending (most recent first)
- Click column header to sort by that column
- Clicking the already-active column toggles direction (asc/desc)
- Clicking a different column: sets new column as active, direction = ascending (except Date defaults to descending)
- Sort indicator: chevron up = ascending, chevron down = descending
- Sorting resets pagination to page 1
- Sort is client-side only (within the loaded page of data)

### Row Click
- Entire row is clickable
- Calls `onSelectRun(run.run_id)` which navigates to `/run/{runId}`
- Cursor: pointer on hover

### Feedback Badge Click
- "Needs feedback" badge uses `stopPropagation` to prevent row click
- Navigates to `/run/{runId}#feedback` (Phase 4 behavior, preserved exactly)

### Pagination
- Page size: 100 rows
- API call: `GET /api/runs?offset={page*100}&limit=100`
- Page change scrolls to top of the table container
- Keyboard: page buttons are focusable, activated with Enter/Space

### Keyboard Navigation
- Tab moves focus between: sort header buttons, table rows, feedback badge buttons, pagination buttons
- Each table row is focusable (tabindex="0") and activates on Enter/Space
- Focus visible: 2px solid #3b82f6 outline with 2px offset (existing global style)

### Sticky Header
- `<thead>` uses `position: sticky; top: 0` so column headers remain visible when scrolling
- Header row gets `z-index: 10` (z-header token) to stay above table body content
- White background on header prevents content showing through

## Responsive Behavior

### Desktop (>= 768px)
- Full table with all 6 columns visible
- Table fills container width, filename column flexes

### Narrow Viewport (< 768px)
- Table container gets `overflow-x: auto` for horizontal scrolling
- Minimum table width: 640px (sum of all column minimums)
- No columns hidden -- horizontal scroll preserves all data
- This matches the "desktop-first" scope from REQUIREMENTS.md ("Mobile responsive layout" is explicitly out of scope)

---

## Accessibility

- Semantic `<table>`, `<thead>`, `<tbody>`, `<th>`, `<tr>`, `<td>` elements
- `<section aria-label="Previous runs">` on container
- Sort buttons in `<th>` elements with `aria-sort="ascending"`, `aria-sort="descending"`, or `aria-sort="none"`
- Table rows with `role="link"` and `tabindex="0"` for keyboard navigation
- Status icons have `aria-hidden="true"` (text label provides the information)
- Feedback badges have descriptive `title` attributes
- Pagination Previous/Next buttons have `aria-label="Previous page"` and `aria-label="Next page"` respectively
- `prefers-reduced-motion`: Loader2 spin animation disabled (existing global CSS rule)
- Focus visible: 2px solid #3b82f6 outline (existing global rule in index.css)
- Color is never the sole indicator -- every status has both icon + text label

## Data Formatting Rules

| Field | Format | Example | Null Handling |
|-------|--------|---------|---------------|
| Date | `toLocaleDateString({month:'short', day:'numeric'}) + toLocaleTimeString({hour:'2-digit', minute:'2-digit'})` | Mar 23, 2:15 PM | never null (started_at is required) |
| Duration | `{min}m {sec}s` or `{sec}s` if < 60 | 3m 42s | em-dash character |
| Cost | `toFixed(2)` with dollar sign prefix | $0.12 | em-dash character |
| Filename | raw string, no truncation, natural line wrap | Smith_CV_2024.docx | never null |
| Status | lowercase from API, displayed as capitalized label | "complete" -> "Complete" | never null |
