BEFORE pattern (all 10 parsers follow this):
```python

    max_tokens=300, response_format=response_format,
    purpose="...", context={...}, caller_file=get_caller_info()
)
start_time = time.time()
response = client.chat.completions.create(
    model="gpt-4o-mini", messages=messages,
    response_format=response_format, temperature=0.1, max_tokens=300
)
elapsed_time = time.time() - start_time

```

AFTER pattern:
```python
result = call_llm(stage="parser_{type}", messages=messages, response_format=response_format)
```
