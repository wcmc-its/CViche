## Minimal Frontend Impact

The only frontend-adjacent change is **D-08**: the WebSocket COST_UPDATE event payload gains a `provider` field (string, default `"openai"`).

### Current COST_UPDATE handler (PipelineViewer.tsx:362-373)

The handler reads `total_cost`, `total_tokens`, `input_tokens`, `output_tokens` from the event. The new `provider` field will arrive in the payload but **does not need to be displayed** in Phase 19.

### Required TypeScript change

Add `provider?: string` to the COST_UPDATE event type interface so the field is accepted without type errors. No rendering changes.

```typescript
// In the COST_UPDATE branch of the WebSocket handler:
// data.provider will be present ("openai") but is not displayed in Phase 19.
// It should be accepted in the type to avoid unknown-property warnings.
```
