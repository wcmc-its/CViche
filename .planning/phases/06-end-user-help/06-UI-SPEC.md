## Typography

| Role | Size | Weight | Line Height | Tailwind Class | Usage in this phase |
|------|------|--------|-------------|----------------|---------------------|
| Body | 14px | 400 (normal) | 1.5 | `text-sm text-gray-700` | Paragraph text, FAQ answers, help content prose |
| Label | 12px | 400 (normal) | 1.5 | `text-xs text-gray-500` | TOC links, attribution line, "Back to..." link text |
| Heading | 18px | 600 (semibold) | 1.25 | `text-lg font-semibold text-gray-900` | Section headings (What is CViche?, Getting Started, etc.) |
| Page title | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold text-gray-900` | "Help & Support" page title |

Two weights only: 400 (normal) and 600 (semibold). Consistent with Phase 4 and Phase 5 typography contracts.

Rationale: This is a long-form content page. Body at 14px/1.5 ensures comfortable reading. Section headings at 18px semibold provide clear visual anchors for scanning a scrollable page. The page title at 20px provides a single top-level focal point. FAQ question text uses Body weight at semibold (14px/600) to distinguish questions from answers without adding a third typography role -- achieved via `text-sm font-semibold text-gray-900`.

## Responsive Behavior

### Desktop (>= 768px)

- Card container: `max-w-2xl` centered, `p-8` padding
- Full content width within card
- All sections visible, single-column reading layout

### Narrow Viewport (< 768px)

- Card container: full width with `p-6` padding (drops to p-6 from md:p-8)
- Content remains single-column, naturally responsive
- No content hidden -- all sections and TOC visible
- This matches the "desktop-first" scope from REQUIREMENTS.md ("Mobile responsive layout" is explicitly out of scope)

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Page landmark | `<main>` element wraps the entire page |
| Card landmark | `<section aria-label="Help and support">` on card container |
| Navigation landmarks | `<nav aria-label="Back navigation">` for back link, `<nav aria-label="Table of contents">` for TOC |
| Heading hierarchy | `<h1>` for page title, `<h2>` for section headings -- no skipped levels |
| Link labels | Help icons use `aria-label="Help and support"` (icon-only links) |
| Email link | Plain text email visible (not hidden behind "click here" pattern) |
| Focus visible | 2px solid #3b82f6 outline (existing global rule in index.css) |
| Reduced motion | Smooth scroll respects `prefers-reduced-motion` via `scroll-behavior` CSS or JS check |
| Color independence | No information conveyed by color alone -- all content is text-based |
| Reading order | DOM order matches visual order (title, TOC, sections 1-5, attribution) |
