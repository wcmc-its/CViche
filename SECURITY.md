# Security Policy

## Reporting a vulnerability

Email **paa2013@med.cornell.edu**. Please do not open a public issue or pull request for a security problem.

Include the affected endpoint or file, steps to reproduce, and the impact you expect. CViche handles uploaded CVs that contain personal data, so do not send real CVs or anyone's personal information. Use synthetic test data.

## Supported versions

Only the latest code on the `dev` branch is supported. Fixes are not backported.

## Scope

`.oss-scanner/threat_model.md` lists what is in and out of scope and how we rate severity.
